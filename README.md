# 🌦️ Weather Data Analysis | Exploratory Data Analysis (EDA)

## 📌 Project Overview

Weather Data Analysis is a Python-based data analytics project focused on analyzing historical weather data to discover trends, patterns, and relationships among various meteorological parameters.

The project applies **Data Cleaning, Exploratory Data Analysis (EDA), Statistical Analysis, and Data Visualization techniques** to extract meaningful insights from weather datasets.

This project demonstrates practical skills in **Python programming, data preprocessing, visualization, and analytical problem-solving**.

---

# 🎯 Project Objectives

- Perform exploratory data analysis on historical weather data.
- Clean and preprocess raw weather datasets.
- Analyze temperature, humidity, wind speed, precipitation, and pressure trends.
- Identify relationships between weather attributes using correlation analysis.
- Create informative visualizations to communicate data-driven insights.
- Improve understanding of weather patterns through statistical analysis.

# 📊 Dataset Information

**Dataset:** Weather in Szeged (2006–2016)

The dataset contains historical weather observations collected over several years.

### Key Features:

- Date and Time
- Weather Summary
- Precipitation Type
- Temperature (°C)
- Apparent Temperature
- Humidity
- Wind Speed
- Wind Bearing
- Visibility
- Atmospheric Pressure
